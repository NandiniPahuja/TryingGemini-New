# Project: Calculator App

## Objective:
Create a simple calculator application using Node.js.

## Tasks:

1.  **Jira Ticket Creation:**
    *   Create a new Story ticket in the "IRAI" project.
    *   The story should be named "Test2".
    *   Add the following sub-tasks to the story:
        *   Create a new GitHub repo called "TryingGemini".
        *   Push the code to GitHub.
        *   Run the app to check if everything is fine.

2.  **GitHub Repository:**
    *   Create a new public GitHub repository named "TryingGemini".

3.  **Development Workflow:**
    *   For each sub-task, push the code to the GitHub repository.
    *   Update the status of the corresponding Jira ticket accordingly.

4.  **Final Verification:**
    *   Run the application to ensure it is working correctly.
